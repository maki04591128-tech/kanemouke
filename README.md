# kanemouke – 資産形成シミュレーター「ふやすノート」

## これは何か

継続的な収益化を目指す**無料の資産形成計算ツール集**（静的サイト）。
サーバー不要・ホスティング費ゼロで運用でき、Google AdSense と証券会社アフィリエイトで収益化する前提で設計している。

このリポジトリは自動実行される定期タスクによって少しずつ育てられる。
**新しい企画に浮気せず、このアイデアを毎回ブラッシュアップすること。**
（過去のセッション記憶は参照しないルールのため、企画・進捗はすべてこの README とコード自体に記録する。次回以降はこのファイルを読んで続きから作業する。）

## なぜこのアイデアか

- 日本では新NISA / iDeCo 関連の「積立シミュレーター」検索需要が継続的に大きい。
- 計算ロジックのみで完結し、外部APIやデータベース、実店舗対応が不要 → 完全に静的サイトとしてAIエージェント単独で作り切れる。
- 投資助言をせず「入力値に基づく機械的な試算」に徹することで、金融商品取引法上のリスクを抑えられる（要免責事項の明記）。
- マネタイズ経路が明確：
  1. Google AdSense（記事・計算結果ページの広告枠）
  2. 証券会社・ロボアドバイザーのアフィリエイト（SBI証券、楽天証券、WealthNaviなど）
  3. 将来的にはメール登録による資産形成講座・アフィリエイト誘導も検討

### URLパラメータ共有機能（`js/share.js`）について

全ツールページの入力欄（`.panel` 内の `id` 付き `<input>`/`<select>`）は `js/share.js` が自動的に走査するため、**新しいツールページを追加する際は特別な実装をせず、他ページと同様に `<script src="../js/share.js"></script>` を末尾のscriptタグに追加し、ページ内に以下のHTMLブロックを1つ置くだけで動作する**（`id`は固定でよい。既存24ページと同じ場所＝結果表示エリアの下・広告枠の上に配置している）。

```html
<div class="share-box" id="share-box">
  <div class="share-box-text">
    <strong>この条件の結果をURLで共有</strong>
    <p>入力した条件をそのまま再現できるURLです。SNSやメモ・友人との共有にご利用ください。</p>
  </div>
  <div class="share-box-controls">
    <input type="text" id="share-url-input" readonly aria-label="共有用URL">
    <button type="button" id="share-url-btn" class="share-btn">URLをコピー</button>
  </div>
  <span id="share-url-feedback" class="share-feedback" role="status"></span>
</div>
```

動作：ページ読み込み時にURLクエリパラメータ（例: `?initial=500000&monthly=30000&rate=5&years=20`）を各入力欄の`id`と照合して値を復元し、既存の`input`/`change`イベントリスナーを発火させて（ページ固有のセレクトによる表示切替ロジック等も含めて）自動的に再計算させる。「URLをコピー」ボタンは現在の入力値からクエリパラメータ付きURLを組み立て、クリップボードにコピーする（`navigator.clipboard`が使えない環境では`textarea`+`execCommand("copy")`にフォールバック）。入力欄はページごとに異なる`id`・型（number/range/select）を持つが、共通で`.panel`内に置かれているという構造だけを前提にした汎用実装のため、ページ側のJS（`js/xxx.js`）は一切変更不要。

### 「よくある質問」の構造化データ（`FAQPage` JSON-LD）について

各ツールページの`<section class="article-section">`内、`<dl>`に`<div class="faq-item"><dt>質問</dt><dd>回答</dd></div>`の形で並んでいる「よくある質問」は、`<head>`内の`<script type="application/ld+json">`に`FAQPage`スキーマとして機械的に反映している（`dt`/`dd`のテキストからHTMLタグを除去し`Question`/`Answer`に変換したもの）。**新しいツールページにFAQを追加する際は、他ページと同じ`faq-item`のHTML構造で書けば、既存パターンに倣ってJSON-LDを追加するだけで対応できる**（`dt`/`dd`に`id`属性を付けている箇所＝結果表示の内訳リストとしての流用は対象外。例：`ideco-simulator.html`）。
