# kanemouke – 資産形成シミュレーター「ふやすノート」

## これは何か

継続的な収益化を目指す**無料の資産形成計算ツール集**（静的サイト）。
サーバー不要・ホスティング費ゼロで運用でき、Google AdSense と証券会社アフィリエイトで収益化する前提で設計している。

このリポジトリは自動実行される定期タスクによって少しずつ育てられる。
**新しい企画に浮気せず、このアイデアを毎回ブラッシュアップすること。**
（過去のセッション記憶は参照しないルールのため、企画・進捗はすべてこの README とコード自体に記録する。次回以降はこのファイルを読んで続きから作業する。）

## なぜこのアイデアか

- 日本では新NISA / iDeCo 関連の「積立シミュレーター」検索需要が継続的に大きい。
- 計算ロジックのみで完結し、外部APIやデータベース、実店舗対応が不要 → 完全に静的サイトとしてAIエージェント単独で作り切れる。
- 投資助言をせず「入力値に基づく機械的な試算」に徹することで、金融商品取引法上のリスクを抑えられる（要免責事項の明記）。
- マネタイズ経路が明確：
  1. Google AdSense（記事・計算結果ページの広告枠）
  2. 証券会社・ロボアドバイザーのアフィリエイト（SBI証券、楽天証券、WealthNaviなど）
  3. 将来的にはメール登録による資産形成講座・アフィリエイト誘導も検討

## サイト構成（現状）

- `index.html` … トップページ（ツール一覧・サイト説明）
- `pages/tsumitate-simulator.html` … 積立複利シミュレーター（メインツール）
- `pages/hitsuyou-gaku.html` … 目標金額から逆算する必要積立額シミュレーター
- `pages/ideco-simulator.html` … iDeCo節税シミュレーター（掛金の所得控除による節税額＋将来の資産評価額を試算）
- `pages/kyouiku-simulator.html` … 教育資金シミュレーター（進路パターン別の教育費目安から、大学卒業（18歳）までの必要積立額を逆算）
- `pages/loan-vs-invest-simulator.html` … 繰上返済 vs 投資 比較シミュレーター（住宅ローンの繰上返済（期間短縮型）と、同じ資金を運用に回した場合とで、軽減できる利息総額と想定運用益を比較）
- `about.html` … 運営者情報（お問い合わせ先）
- `privacy.html` … プライバシーポリシー（Cookie・広告配信・アフィリエイトの説明）
- `disclosure.html` … アフィリエイト・広告表記について
- `css/style.css` … 共通デザイン
- `js/tsumitate.js`, `js/hitsuyou.js`, `js/ideco.js`, `js/kyouiku.js` … 各計算ロジック（Chart.js で推移グラフ表示）
- `sitemap.xml`, `robots.txt` … 検索エンジン向け（`sitemap.xml` 内のURLは仮の `https://example.com/` のため、本番ドメイン確定後に置換が必要）
